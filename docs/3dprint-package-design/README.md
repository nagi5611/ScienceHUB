# 3Dプリント 申請・管理 — デザイン一式

松山南高校 自然科学部 / 3Dモデル班の ScienceHUB 内アプリ。
**生徒用の申請フォーム**と**管理者向けの管理画面**の2つをまとめたデザインパッケージです。

## 中身

```
index.html                  … 入口（2つのアプリへのリンク）
3Dプリント予約.html          … 生徒用：依頼・予約の申請
3Dプリント管理.html          … 管理者用：申請の管理 / シフト・設定

admin/                      … 管理画面の実装
  admin.css
  core.js                   … ドメインロジック（日時・シード・シフト・CSV・保存）
  ui.jsx                    … ヘッダー / カレンダー / ドロワー / モーダル / トースト
  reserve.jsx               … 申請の管理（時間単位の確定・取り消し）
  move.jsx                  … 別の日へ変更
  shifts.jsx                … シフト表（ドラッグ塗り） / 担当者 / 外部連携
  settingsScreen.jsx        … シフト・設定の画面
  App.jsx                   … 2画面の切替と状態管理

css/, js/, assets/          … 生徒用フォームの実装（core.js + React）
ds/colors_and_type.css      … ScienceHUB デザインシステムのトークン
ds/assets/icon-192.png      … 自然科学部エンブレム
```

## 開き方

フォルダ構成を崩さずに展開し、**`index.html`** をブラウザで開いてください。
React 18 と Babel を CDN（unpkg）から読み込むため、初回はインターネット接続が必要です。
Google Fonts（Inter / Noto Sans JP）も読み込みます。

## 注意

- これは **デザイン確認用のプロトタイプ** です。データは各ブラウザの `localStorage` に保存され、サーバーへは送信されません。
- 申請データは起動時に自動生成されます。フッターの「データを初期化」でリセットできます。
- 管理画面の Discord「テスト送信」だけは実際に Webhook を叩きます（URLを入れた場合のみ）。本番実装ではサーバー経由にしてください。
- ダウンロードされる STL はプレースホルダのテキストです。本番では署名付きURLから取得します。
- 本番コードとしてそのまま貼るものではなく、既存のコードベース（React / Next.js など）で再現するための参照実装です。

## 主な機能

### 生徒用（3Dプリント予約.html）
- 4週カレンダー＋日別タイムライン（6:00〜20:00、30分刻み）
- 依頼（STL提出・16:30〜20:00 を占有）と予約（時間だけ確保）の2種
- 担当者のシフトがある日のみ受付、重複申請ガード
- 申請ポップ（機種・時間ホイール・ファイルドロップ・申請者）

### 管理画面（3Dプリント管理.html）
- **申請の管理**：4週カレンダー、右にその日の申請（依頼／予約を分離）、30分単位で確定・却下・取り消し
- **別の日へ変更**：空き／満枠／担当なしを色分けし、満枠・担当なしは強制チェックで移動可
- **ダウンロード**：申請書テキスト、STLファイル名、その日の一括出力
- **シフト表**：担当者を選び、カレンダーをドラッグでなぞって一括追加・削除。曜日見出しクリックでその月の同曜日を一括切替。日付には担当者カラーのドット
- **担当者**：追加・編集・削除（名前 / HR 101〜309 / 番号 / Discord ID / カラー）
