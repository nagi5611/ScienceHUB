# シミュレーション依頼における SMS 認証への同意

**バージョン ID:** `2026-07-25-ja-v2`

ScienceHUB のシミュレーション依頼（FDS 等）を利用するにあたり、以下に同意します。

1. **送信内容** — 本人確認のため、登録した携帯電話番号あてに認証コードを含む SMS を送信することに同意します（宣伝・販促目的ではありません）。
2. **利用目的** — 本人確認、不正利用の防止、依頼に関する必要な連絡のため利用します。
3. **第三者提供** — SMS 送信に Google Firebase Authentication を利用します。
4. **保管と有効期限** — 検証済み番号はアカウントに紐づけて保管し、同意記録を監査ログに残します。**認証の有効期限は完了から1年**で、期限後は再認証が必要です。
5. **通信料** — SMS 受信の通信料は利用者負担となる場合があります。
6. **問い合わせ** — diorama@mmh-virtual.jp

画面上でチェックボックスによる明示的同意を取得してから SMS を送信してください。
