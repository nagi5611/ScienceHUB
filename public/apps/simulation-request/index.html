      電話番号の認証

      シミュレーション依頼（FDS）の本人確認のため、日本国内の携帯電話番号に認証コードを SMS で送信します。認証の有効期限は 1年で、期限後は再認証が必要です。

      モーダルを開くと reCAPTCHA が表示されます。先に「私はロボットではありません」にチェックし、その後「認証コードを送信」を押してください。

      SMS が届かないとき（よくある原因）
      • Firebase の API は成功していても、キャリアが海外経由 SMS を拒否していることがあります（ドコモ「海外事業者からのSMS拒否」、au/ソフトバンクの迷惑 SMS ブロックなど）。my ドコモ / au / My SoftBank で設定を確認してください。
      • Firebase Console → Authentication → Settings → SMS region policy で 日本（JP） が許可されているか確認してください。
      • 開発切り分け: Authentication → Phone → テスト用の電話番号（固定コード）で同じ画面から試す。
      • 送信ログ: GCP の Identity Platform のアクティビティログ で SendVerificationCode を確認（プロジェクト管理者のみ）。
